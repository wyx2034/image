返回方式

URL 模式返回临时直链，24 小时后失效；Base64 直接把图片数据塞进响应体（4K 时响应可达 30MB+）。

7

高级参数

▶
连拍张数 （上游 n 只支持 1，这里串行补发）

一次点「生成」就串行发出 N 次请求，每张都会进历史。适合同一提示词抽卡对比。第 2 张起会自动间隔 0.4s。

附加参数 JSON

合并进请求体，同名键以此处为准，选择器里改不动的值也能在这里强制指定。上游支持的键：model · prompt · size · n · watermark · response_format · output_format · prompt_extend；images 由参考图自动填充，不可覆盖。
